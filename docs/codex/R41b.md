## Goal (what Anh should SEE on his phone and tablet, via the preview link)
1. Tap the centred picture on the Work page: the same open as desktop (puff, inward bend, grows to full screen, zooms into the project header), in one smooth motion, starting at once (no visible wait).
2. Back (iOS swipe-back, Android back button, the back link): the same inward-bend shrink into the strip, landing on THE SAME project the visitor opened, centred, no jump.
3. The Work page project title animates like desktop: fades out while the strip moves, plays the smear on the project the strip settles on.

## What changed in the engine since R41 Part A (read the code, do not trust R41-engine-needs.md)
- R42 / R42b: projects open INSIDE the Work page (same-document page swap, src/work/core.js `createPageSwap`, `swap.open`), no page load; back lands exactly on the card.
- R42c: every open and back plays the bend from a prepared renderer (no flat fallback); back uses a separately HELD renderer (project-transition.js `stashBack` / `takeBack` / `ensureBack`); scrolled-down project pages glide to the header before the shrink.
- R42d: a click uploads the on-screen card picture in one go and starts at once, the header swaps in after the first frame; one spare renderer is reused (`spare`, `parkRenderer`, `recycleFlight`); headers of the centre + 2 neighbours are prefetched at rest.
- The R41 Part A pieces are on work-v2: `createTapGate` (src/work/mode-lite.js, exposed as `mode.tap`), `TRANSITION_POLICY_LITE` (src/settings/tall.js, `enabled: false`), `transition-policy.js` picks desktop / lite policy per mode, tall header rests at `FLIGHT.zEnd`.
- Open timing: R42e (merged 2026-10-31) is Anh's chosen desktop open: workSec 0.85, workCarry 0.4, zoomTailSec 0.55, workPushSec 0.48, inwardAmp 0.01125 (about 1.27 s, soft arrival, long settle). Lite should read the same values unless a phone needs its own (then add them to TRANSITION_POLICY_LITE and say why).

## Steps
1. Wire tap to open: `mode.tap` gate on the frame's pointerdown / click (R41-engine-needs.md item 1 is the idea; adapt it to the current click handler and `swap.open`). Flight sized from the viewport captured at tap (`mode.tap.viewport`), not live innerWidth / innerHeight (the address bar moves).
2. Prepare without hover: idle prepare of the centred picture after the strip rests (`TRANSITION_POLICY_LITE.idleMs`) + touchstart fallback; the R42d urgent path (one-shot upload from the card picture) must work on touch too, so a cold tap starts at once. Respect the lite caps (grid 20, maxDpr 1.5, one prepared renderer, dispose on scroll / drag / hidden / pagehide / resize). Remove the `isTall()` gates that block flight / bulge / playBack.
3. Back to the same project (R41.md B1): with the transition on (same-page swap: the strip under the project is kept) and with it off (weak device, reduced motion, Save-Data: no animation, but the strip opens on that project). Handle bfcache (pageshow persisted) and a fresh load (sessionStorage / the pxb record).
4. Title smear on lite (R41.md B2): a lite title that reuses `createSmear`, with phone / tablet sizing, the same trigger logic as desktop (out while moving, smear on settle, cancel / restart on fast swipes), theme ink, fallbacks (reduced motion = plain fade; no WebGL / weak device = smear's CSS path). Replaces the old per-letter `.work__name` in lite only.
5. Turn it on: `TRANSITION_POLICY_LITE.enabled: true`.

## Targets (pass / fail)
- Tap to first moving frame <= 100 ms at 60 Hz, <= 250 ms at 4x CPU (cold and warm), on emulated 390x844, 430x932, 768x1024, 1024x768.
- No black frame, no stall over ~20 ms mid-motion, no doubled edges, motion curve continuous (AGENTS.md 7), 60 and 120 Hz paced.
- Back lands on the opened project: 3 projects x (transition on, transition off) x (bfcache, fresh load) = 12 cases, landing within 1 px, 0 wrong projects.
- A tap during a fling / a drag / a long press never opens (gate unchanged); a double tap opens once.
- Title: smear first frame <= ~20 ms at 4x CPU; frame time while swiping unchanged vs work-v2; 20 fast swipes in 3 s leave no stacked or ghost smear.
