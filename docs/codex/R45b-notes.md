## What was built
- Same flight and look as desktop (home-flight.js `look: 'pixel'`: pointer-fx grid + synthetic brush, WORK_PTR numbers unchanged, so the grid is 38 columns on a 390 px screen = ~10 px cells; frame time not measured on a phone).
- Geometry: `workStartLayout / firstCardRect / cardImage` follow the phone Work page when `isLite()` (src/work/tall.js numbers inlined: tall = vertical strip, image TALL.frame of the width, gap TALL.gapV x image height; tablet landscape = side strip, TABLET.frameH). Neighbours = the cards above and below (or left / right) that show at the start.
- Home (src/tall-home.js): the menu's Work link (`mountTallMenu().link`) starts `initHomeToWork` (new options link / video / wrapper / lift / beforeFlight; `closeNow()` closes the menu with no animation). The flight code is loaded after the loader on a normal visit (first load stays light) and at once on a return. A return (#pxg painted by index.html) skips the loader and calls `arriveFromWork`.
- Work (src/work/core.js, home-return.js): `initHomeReturn` now runs on touch too (`touch`, `rectOf` = the strip's own rect incl. warp offset). Triggers: Back (popstate), the wordmark, and a swipe to the right starting > 24 px from the edge (dx > 70 and > 2 x |dy|). The Work page's saved place (`work-lite-place`) is cleared at the tap so it opens on the first card.
- No black frame: index.html got the same pagereveal hold as work/index.html (the Work frame is held until the hero video plays, then `skipTransition()`, 1.5 s cap). Where cross-document view transitions are missing (iOS < 18.2) the first-paint layer (#pxh / #pxg) covers it.
