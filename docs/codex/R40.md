# R40: separate the code by mode (desktop / phone+tablet) so two agents can work in parallel, with NO visible change

Planner: Cowork (Claude), 2026-10-11, approved by Anh. Builder: ONE agent alone (no parallel work while R40 runs). AGENTS.md applies.
This brief wins over docs/requests.md. Branch: `refactor/r40-mode-split`, created from `work-v2` (which now contains R37-R37e + R38).
Time budget: this is a larger restructure; aim for ~60-90 min, commit WIP after each part, stop and report past ~2 h.

## Goal (what Anh should SEE)
Nothing. The site looks and moves exactly as before on every page and device. What changes is the file layout: after R40, a
desktop agent and a phone/tablet agent can each work almost entirely in their own files, so merges rarely conflict.

## Why
Planned next: one agent on desktop, one on phone/tablet, on two branches, merged often. Today the main conflict points are:
- src/work.js (953 lines): the Work page for ALL modes; `lite` (= tall OR tablet landscape, line ~51) appears ~50 times inside shared
  functions (scroll, snap, inertia / coast, layout, input), plus `TLm` (work/tall.js) hooks.
- src/timeline.js (495 lines): every tuning value for every mode.
- src/styles/base.css (520 lines): shared basics mixed with desktop-only rules.
- src/project.js: already dispatches to project-page.js / project-page-tall.js (small tidy only).

## Parts (commit after each; run the FAST check after each, the FULL list once at the end)
1. Work page split:
   - src/work/core.js: shared state and plumbing (data / pool loading, the strip model, item creation, image loading, the shared rAF
     tick skeleton, GL hooks, back hand-off wiring).
   - src/work/mode-desktop.js and src/work/mode-lite.js (tall + tablet landscape): everything currently behind `lite` / `!lite`
     branches, exposed through ONE small mode interface the core calls (e.g. { inputSetup, coast(dt), snapParams, layout(),
     onResize(), perFrame(dt), teardown }). Keep names plain and document the interface at the top of core.js.
   - src/work.js becomes a short entry: pick the mode (layout-mode.js), import the mode module, start the core.
   - Rule: after R40, core.js contains NO `lite` / `tall` / `tabletLand` checks. If something truly differs per mode, it is a mode
     hook.
2. Settings split: src/settings/shared.js, src/settings/desktop.js (WORK, WORK_*, TRANSITION, CARDS, BEND, ... desktop blocks),
   src/settings/tall.js (TALL and lite-only values). src/timeline.js stays as a thin re-export (`export * from ...`) so no import
   elsewhere changes. The ?tune panels keep working (they edit the same objects).
3. CSS split: base.css keeps tokens (incl. R38 theme tokens), reset, fonts, shared type; desktop-only rules move to
   src/styles/desktop.css (loaded where base.css is loaded today, for desktop pages / modes exactly as now); tall rules stay in
   tall.css / tall-project.css. The cascade order must not change the result (check computed styles on the sampled pages).
4. Project page tidy: keep src/project.js as the dispatcher; move any desktop-only setup into a desktop helper and keep the tall
   branch where it is, so desktop and tall edits land in different files.
5. Ownership: docs/OWNERS.md with three lists: DESKTOP (mode-desktop.js, settings/desktop.js, desktop.css, work.css, project.css,
   project-page.js, project-transition.js, bulge-gl.js, flight-curve.js, home desktop sections, cards / frame GL ...), LITE (mode-lite.js,
   settings/tall.js, tall*.css, tall-home.js, work/tall.js, work/tall-guard.js, project-page-tall.js, tall-menu.js, layouts-tall.json,
   layouts-tablet.json), SHARED (core.js, settings/shared.js, base.css, layout-mode.js, data.json, media, docs/requests.md, AGENTS.md,
   CLAUDE.md, build config). Fill it from the actual files; every tracked file under src/ is in exactly one list.
6. Ownership check: tools/owners-check.mjs (tracked, no new packages): reads docs/OWNERS.md and the branch's changed files
   (`git diff --name-only work-v2...HEAD`) and the env / argument `--side desktop|lite`; prints a WARNING for files of the other side and a
   NOTE for shared files. Add `npm run owners -- --side desktop` (package.json scripts entry only; no dependency change, this one
   scripts line is allowed). Not a hard failure.
7. AGENTS.md: new section "Parallel work" (ownership, run owners-check before each commit, shared-file edits small and listed in
   the request notes, each side protects the other: desktop agent runs a tall smoke test at 390x844 (home, menu, one project), lite
   agent runs the desktop compare 542/542; merge into work-v2 often, one branch at a time, by Cowork; R24c mode switch only after
   both are merged; separate dev ports: desktop 5199, lite 5200). Make the dev port and compare's port configurable
