### A2. Home -> Work transition
Recommended architecture (same idea as R42, which removed the page-load snap for projects): the homepage warms the Work page IN ITS OWN DOCUMENT after the hero has settled and the browser is idle (import the Work chunk, build the strip paused and hidden, prepare the flight renderer and the first card's texture, sliced so no frame hitches; never before first paint; respect Save-Data). On click: the flight plays from the hero's visible rectangle (frameState / the mask's current box) to the first card's rest rectangle on the Work page (WORK_V2 frame size, the current mode Side / Vertical as the Work page would start), the Work page is revealed under it at landing, `history.pushState` to /work/. If anything is not ready or fails: plain navigation to /work/ (today's behaviour), never a broken state.
Alternative only if the in-document Work costs too much on the homepage (report numbers): a cross-document hand-off like R25 (sessionStorage + the inline head script paints the overlay on first paint). Then the landing must still show NO visible hold; measure the hold and report it.
- Motion: the R42 back flight (shrink with inward bend, current back strength, Anh kept full strength in R42f) PLUS a smear term in the same shader: displacement along the flight's screen velocity (sample offset proportional to velocity, smooth falloff toward the leading edge), optional small RGB split, strength rising with speed and exactly 0 at rest, so the landing frame equals the Work page's own card pixels (no pop). Start values (tune by eye, all in ?tune): smearStrength 0.08 of the picture size at peak speed, smearRGB 0.006, crossfade over the middle 60 % of the flight (video frame -> first card image, both drawn with the same crop as their own end states), duration ~1.1-1.3 s (match the R42e open feel, 1.27 s), same ease family as R42e.
- The video: use the CURRENT video frame as the start texture (the engine already has WebGL video textures); if a video texture is not possible on a browser, use the poster.
- Spawned images and the image trail fade out in ~0.15 s at the start (they are DOM layers; do not try to smear them unless it is cheap and looks right). Hover captions hide at the start.
- Wordmark: big -> small DURING the flight (A4).
- Work page after landing: exactly the state of a direct visit to /work/ at rest (title, counter, labels, rulers in their rest state; play the Work page's own title entrance at the landing, the R33 smear reveal, timed so it starts as the card lands).
- First frame after the click < ~20 ms (AGENTS.md 7). Continuous speed, no stop-then-go.
