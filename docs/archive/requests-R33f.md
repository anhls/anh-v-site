### 1. The title ALWAYS leaves with the shader (Anh: "sometimes the out animation, most of the time it just fades out")
Cause found by Cowork in v2-ui.js (the title block of `frame`): when the strip starts moving, `if (smear.playing) smear.abort()` runs the shader leave ONLY while the enter smear is still playing; when the enter has finished and the title is the plain DOM text, the else-branch just lowers the DOM opacity over `titleOutSec` (a plain fade). So the shader leave appears only if the user scrolls within about a second of the title forming.
- Fix: when the strip starts moving and the title is visible as DOM text (not playing, opacity above 0), start a SHADER LEAVE from the fully formed state: the overlay draws the title at progress u = 0.5 (the middle of the triangle, p = 1: pixel-identical to the DOM text), the DOM title is hidden (`visibility`, no pop: the same exact-match swap check as the enter: under 0.5 % of the box pixels differ by more than 8 levels at 1920 / 2560, DPR 1 and 2), then plays the leave 0.5 -> 1 over `leaveSec` (0.7, scaled by the remaining progress as `abort` does). Add the entry point in smear.js (e.g. `leaveFromRest(opts)`) next to `abort()`; keep the one scrubbed value.
- Remove the plain opacity fade (`titleOutSec` path) for the normal case; it stays ONLY for reduced motion, ?fx=0, ?gl=0 / a lost GL context (then the 0.2 s fade as now).
- Interruptions: the strip stops before the leave ends -> the enter continues from where the leave got to (one scrubbed value, no restart from zero, no flash); a project change during a leave swaps the title text only once the leave has finished (while the overlay is blank), then the enter plays; a single notch / short slow drag that keeps the same project: the title still leaves and re-enters (so the user always sees the response).
- Checks (read the overlay pixels back, not just the opacity): leave from rest, from mid-enter, from mid-leave, at 0 / 0.2 / 0.5 / 1.0 / 2.0 s after the enter started: in every case the overlay shows the distortion (corner streak + noise) and the DOM title opacity never fades while the overlay is drawing; zero frames where the title is a plain CSS fade in the normal path (log it); contact sheet of a leave from rest at 0 / 0.1 / 0.2 / 0.35 / 0.5 / 0.7 s in tools/scratch/r33f-shots/; no ghost left after each leave (overlay alpha 0).
