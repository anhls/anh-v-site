### Part C: fixes (cheapest first; each is its own commit; re-measure the SAME scenario after each and keep a fix only if it helps or is free; the look must not change)
6. C1, load only what shows. The other items load AFTER the transition ends (`done()`), in small slices while the page is idle (about 1 item per 50 ms or requestIdleCallback, never while a transition or the first input burst is running; if the user scrolls early, load the items nearest to the viewport along the strip axis first). Check: the number of textures uploaded before the shrink starts (was 39), the time to the first shrink frame, and a fast wheel scroll right after the return (a card must never show an unloaded / empty picture for more than 1 frame at normal speed; report the worst case at a hard flick).
